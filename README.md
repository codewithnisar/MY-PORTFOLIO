# Nisar Ali — Digital Craft Portfolio

Personal portfolio website of **Nisar Ali** — Web Developer, UI/UX Designer & Creator behind **CodeWithNisar**.

## 📁 Project Folder Structure

```
portfolio/
├── index.html              # Clean semantic HTML5 page
├── manifest.json           # Web App Manifest (PWA support)
├── robots.txt              # Search engine directives
├── sitemap.xml             # Search engine XML sitemap
├── sitemap.xsl             # XSLT Stylesheet for XML Sitemap visual rendering
├── .gitignore              # Git ignore configuration
├── README.md               # Project documentation
│
└── assets/                 # Modular project assets
    ├── css/
    │   └── style.css       # Complete layout, components, themes, animations, & media queries
    ├── js/
    │   ├── theme.js        # Dark/Light theme state & LocalStorage toggle
    │   ├── modal.js        # Case study popup modal controller
    │   └── main.js         # Scroll reveals, form validation, & smooth scroll navigation
    └── images/             # Visual assets, thumbnails, & icons
```

## 🚀 Features

- **Modular Architecture**: Clean separation of HTML, CSS, and JS.
- **Dark / Light Mode**: Theme toggler with persistence via `localStorage`.
- **Case Study Modal**: Popup modal for project details with keyboard support (`Esc` key).
- **Interactive Animations**: Smooth scroll reveal effects using `IntersectionObserver`.
- **Form Validation**: Contact form handling with budget selector & toast notification feedback.
- **SEO & PWA Ready**: Includes meta tags, OpenGraph data, Web Manifest, Robots.txt, and a styled XML Sitemap.

## 🛠️ Built With

- HTML5 (Semantic Structure)
- CSS3 (Custom Properties, Flexbox, CSS Grid, Responsive Design)
- JavaScript ES6+ (Modular Scripts)
